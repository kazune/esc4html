# esc4html

標準入力のテキストをHTML用にエスケープする、小さなフィルターコマンドです。

## 背景と設計方針

シェル上でHTMLを組み立てるとき、エスケープ処理をその都度書かず、パイプラインに挟める共通のコマンドが欲しい、という目的で作られています。

`esc4html` はUnixフィルターとして、標準入力から読み、標準出力へ書きます。ファイル引数やオプションを持たせないことで、使い方を単純に保ち、引数が誤って `sed` のオプションとして解釈されることも防いでいます。

実装はPOSIX互換の `sh` と `sed` だけに依存します。専用のHTML/XMLツールキットや言語ランタイムを、この処理だけのために追加する必要がないことを重視しています。また、処理内容を短いソースですべて確認できることも意図しています。

責務は `&`, `<`, `>`, `"`, `'` の5文字を決まった文字参照へ置換することだけです。HTMLの構造解析、既存の文字参照の判定、文字コードや改行の正規化、制御文字の削除は行いません。入力は未エスケープのテキストであることを前提とし、対象外のデータを暗黙に変更しない方針です。

これはHTMLサニタイザーではありません。通常のHTMLテキストを埋め込むためのエスケープに用途を限定し、JavaScript、CSS、URLなど、文脈ごとに異なる検証は呼び出し側の責務とします。本文では必須でない引用符も含めた5文字を常に変換することで、モードを持たない予測可能な動作にしています。

## Usage

パイプまたは入力リダイレクトでテキストを渡します。

```sh
printf '%s\n' '<p class="note">Tom & Jerry</p>' | ./esc4html
```

```text
&lt;p class=&quot;note&quot;&gt;Tom &amp; Jerry&lt;/p&gt;
```

ファイルを処理する場合も、引数ではなくリダイレクトを使用します。

```sh
./esc4html < in.txt > out.txt
```

コマンドライン引数は受け付けません。引数が指定された場合は、終了コード `2` で終了します。

## 変換規則

| 入力 | 出力 |
| --- | --- |
| `&` | `&amp;` |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `"` | `&quot;` |
| `'` | `&#39;` |

構造を解析せず、入力を単純に置換します。そのため、既存の文字参照も二重にエスケープされます。例えば、`&amp;` は `&amp;amp;` になります。

HTMLのテキストとして埋め込む内容を対象としています。JavaScript、CSS、URLなど、別の文脈に対するエスケープや検証には使用できません。

## Requirements

- POSIX互換の `sh`
- `sed`

テストと静的検査の実行には、次のツールが必要です。

- [Bats](https://github.com/bats-core/bats-core)
- [ShellCheck](https://www.shellcheck.net/)
- [shfmt](https://github.com/mvdan/sh)

## Test and lint

すべての検査を実行します。

```sh
make check
```

Batsテストだけを実行する場合は、次のコマンドを使用します。

```sh
make test
```
